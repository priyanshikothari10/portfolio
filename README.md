# 👩‍💻 About Me

AI & Data Science student with a strong interest in Cloud Computing, DevOps, and Kubernetes.

This project demonstrates the transformation of a standard React portfolio into a cloud-native, DevOps-ready application using Docker, Kubernetes, NGINX Ingress, and AWS EC2.

RHCSA certified with hands-on experience in Linux (RHEL 9), Git, GitHub, AWS, Docker, Docker Compose, Ansible, and Kubernetes.

---

# 🚀 Project Transformation

## Before

- React + Vite Portfolio
- Local development
- Netlify deployment
- No containerization
- No orchestration

## After

- Dockerized React application
- Docker Hub image
- Kubernetes Deployment
- Replica management
- Namespace isolation
- ConfigMap
- Secret management
- Kubernetes Service
- Horizontal Pod Autoscaler (HPA)
- NGINX Ingress Controller
- Custom Domain Deployment
- Hosted on AWS EC2
